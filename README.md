# SL Budget - Personal Finance PWA for Sri Lanka

AI-powered expense tracking and budgeting application.

## Features
- 🏦 SMS Gateway integration for automatic transaction capture
- 📊 Real-time expense tracking and analytics
- 🤖 AI-powered categorization (Gemini/Claude)
- 📱 PWA with offline support
- 🌏 Multi-language (EN/SI/TA)

## Live
- **App**: https://sl-budget.vercel.app
- **SMS Webhook**: https://us-central1-budget-buddy-1e3e8.cloudfunctions.net/smsWebhook

## Stack
- Next.js 14 + TypeScript
- Firebase Firestore
- Firebase Cloud Functions
- Vercel Deployment
